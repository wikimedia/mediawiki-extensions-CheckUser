# CheckUser

CheckUser is an extension that allows privileged users to check which IP addresses, User-Agent strings,
and Client Hints are used by a given username and which usernames are used by a given IP.

It also provides client-side features, such as "Show IP" buttons for temporary accounts and the UserInfo card.

For more information, see [Extension:CheckUser](https://www.mediawiki.org/wiki/Extension:CheckUser)
